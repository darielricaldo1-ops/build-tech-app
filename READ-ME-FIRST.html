STUDIO / LOCAL EDITION 1.0.0

Your business.
On your computer.

A complete local workspace for business records, quotes, invoices, documents and the BuildTech website. No hosting connection or login is required.

Open the Windows app

  1. Extract the complete ZIP using Extract All.
  2. Open the Windows folder.
  3. Run BuildTech-Studio-1.0.0-Windows-x64.exe.
  4. Start with Business settings. Add clients, quotes and projects as needed.
  5. Use Backups & storage to keep a copy on another drive.

Windows 10/11 x64. No administrator installation, Node.js setup, or separate database is needed for the executable. This build is unsigned and Windows may identify an unknown publisher.

Your files

Windows/ contains the executable and runtime notices.
Source/ contains all application source, the compiled local server and website, included assets, migrations, build scripts and tests.
SHA256SUMS.txt contains file integrity hashes.

Open Source/README.md in a text editor for backup, restore, browser-mode and rebuild instructions. Read the verification record for completed checks and platform limits.

Your information stays local

The Windows workspace is saved in %APPDATA%\BuildTech Studio Local\workspace. The app starts with an empty business database and the bundled website. Existing online records are not automatically imported.

Website edits change the local website. No online website is modified. Email delivery, online payments and hosting are not connected.

Technical verification

The database and file workflows passed tests in Node and Electron on Linux. Chromium checks covered forms, saved website changes, appearance and model floor plans. The Windows executable was cross-compiled and has not been run on Windows in this environment.
